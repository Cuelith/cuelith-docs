# cuelith-docs

Documentazione di Cuelith: il documento di progetto (fonte di verità per lo sviluppo) e le decisioni prese durante il lavoro.

- `decisioni/` — decisioni numerate che completano o cambiano il documento di progetto. In caso di conflitto vale la decisione più recente.

Il documento di progetto completo verrà copiato qui con i nomi reali (passo 11 della Fase 0).
